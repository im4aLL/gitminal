[02 // SYSTEM ARCHITECTURE & CAPABILITIES]

Engineered Like a Systems Runtime, Not a Wrapper Script

Strict unidirectional layering (features -> ui/app -> domain -> lib), deterministic command serialization, and native terminal rendering.

01 // GRAPH ENGINE domain/graph

Two-Cell Lazygit Box-Drawing Lanes

Renders complex branch topologies and octopus merges using East Asian Ambiguous 1-cell glyphs. Switch seamlessly between rounded arc corners (╭ ╮ ╰ ╯ ○ ◎) and WGL4/CP437-safe sharp corners (┌ ┐ └ ┘ +) with cursor-paginated history and instant commit search (/).

Glyphs: U+2500..U+257F Page window: 500 commits
02 // GUARDED GIT CLI domain/git + commands

Serialized Runner & Zero Shell Interpolation

Every Git subprocess spawns via argument arrays with no shell interpretation. Write operations are strictly serialized (one mutation at a time with explicit blocked reasons), credentials in URLs and stderr are automatically redacted, and branch deletion inspects unmerged commit risk before confirmation.

Spawn: argv[] only Safety: Credential Redaction
03 // DIFF & TREE-SITTER features/diff + parsers

Vendored WASM Syntax Highlighting

Working tree, staged, untracked, commit, stash, and conflict diffs render through OpenTUI's unified <diff> primitive with vendored Tree-sitter WASM grammars (TypeScript, Python, Rust, Go, Bash, JSON, YAML, HTML, CSS, Java, PHP). Unchanged context runs collapse cleanly and scroll via J/K/H/L.

View: Unified 1-Gutter Parsers: Offline WASM
04 // INPUT & FOCUS AUTHORITY app/hooks/useHotkeys

Context-Sensitive Keys + Full Mouse Support

A single global key dispatcher resolves precedence (Overlay -> Text Editor -> Native Select -> Focused Region -> Global). Every keyboard action has mouse parity: click to focus and select, double-click to trigger primary actions, click checkboxes/headers, and scroll any viewport with the wheel. Overlay-scoped keys stay inside their modal, so the theme picker's chords never leak into the list behind it.

Regions: 1..9 + Tab Mouse: Click / DblClick / Wheel
05 // COMPLETE REPO SURFACES features/branches..worktrees

Branches, Remotes, Tags [LR], Stashes & Worktrees

Manage the entire Git lifecycle without leaving the viewport: checkout/create/delete branches, prune remotes, inspect tag presence via the fixed-width [LR] / [L↑] / [L?] matrix, pop/apply stashes with untracked files, and create or prune linked Git worktrees. Search results keep their remote prefix, full tag name, stash index, and absolute worktree path.

Tag Matrix: [L R ↑ ?] Frame-Buffer Progress Bar
06 // THEME CATALOGUE & COLOR ENGINE domain/theme

40 Built-In Themes With Dark & Light Tabs

Ships with 40 built-in themes across 26 palette families, from Catppuccin and Tokyo Night to Nord, Kanagawa, Solarized, and High Contrast. Pick from Dark and Light tabs with live search, and every theme is checked against enforced WCAG contrast floors for text, accents, diff signs, and status hues. NO_COLOR, COLORTERM, and TERM still drive truecolor, 256-color, and monochrome fallback.

Catalogue: 40 themes / 26 families Contrast: WCAG checked
07 // USER THEME FILES domain/theme + config

Your Own Palette as One JSON File

Drop a JSON file into the themes directory beside config.json (or point $GITMINAL_THEMES_DIR somewhere else) and it appears in the picker by name. A theme can extend any built-in and only override the tokens it cares about, and the picker's Export control writes the highlighted theme out as a complete file you can edit. theme.json still overrides individual tokens on top of any selected theme, and a broken or oversized file degrades to one warning and never prevents launch.

Format: JSON + extends Export: <name>-custom.json
08 // NATIVE TERMINAL MODE domain/theme/theme.terminal

Adopt the Palette Your Terminal Already Uses

Select Native Terminal and Gitminal asks the terminal for its palette with OSC 4, 10, and 11 queries, then maps the answer onto every token, including guarded secondary text and diff line backgrounds. It works in iTerm2, WezTerm, Kitty, Alacritty, Ghostty, Windows Terminal, and tmux. A terminal that cannot answer falls back to Catppuccin Mocha with one warning, and app.reloadConfig re-detects after a profile change.

Detection: OSC 4 / 10 / 11 Fallback: catppuccin-mocha
